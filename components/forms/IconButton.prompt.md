**IconButton** — a square, icon-only control for toolbars, close buttons, and compact actions. Always pass `label` for accessibility.

```jsx
<IconButton label="Close" variant="ghost"><XIcon/></IconButton>
<IconButton label="Book" variant="solid"><CalendarIcon/></IconButton>
```

Variants: `ghost` / `outline` / `solid`. Sizes: `sm` / `md` / `lg`.
